# Windows companion — planned

No executable or driver is implemented. ViGEmBus is retired; do not silently depend on an abandoned driver for production. Evaluate a maintained signed virtual HID solution, such as a properly licensed current Virtual HID Framework driver, or a maintained vendor implementation. Xbox-compatible behavior is the compatibility target, not a claim of native XInput support.

Native Rust host must share v1 validation, local TLS pairing, rate limits and disconnect cleanup. Driver signing, installer elevation, secure boot compatibility and distribution licensing must be resolved before publishing installation instructions. No fake build command is provided.
